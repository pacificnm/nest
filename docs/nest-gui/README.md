# nest-gui (legacy)

**Do not use.** Nest desktop apps use **[nest-tauri](../nest-tauri/README.md)** with the standard frontend stack:

**Tauri + React + TypeScript + Tailwind** (`ui/` + `src-tauri/`).

See [Desktop frontend platform](../architecture.md#desktop-frontend-platform) and [nest-tauri v1 plan](../plan/nest-tauri-v1.md).

The `nest-gui` crate may remain in the workspace temporarily for app migration only. It is not documented further.
